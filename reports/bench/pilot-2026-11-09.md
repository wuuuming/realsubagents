## Harness findings

1. **realctx rewrites on opus.** realctx's 3 calls (memory edit/merge) ran on the session model because `rewriteModel` is empty in the user's config. The cost was small ($0.039), but it breaks D-13. Fixed: the runner now sets `rewriteModel` and `history.model` to `claude-haiku-5-5` in the per-run config (D-20).
2. **Harness files in the diff.** The saved diff included the seed manifest (2.4 MB) and realctx's project-shared memories (`.pi/realctx/`). Fixed: both are excluded from `diff.patch`; the pilot's diff was cleaned afterwards.
3. **realtasks is not isolated.** Its state lives under the agent dir, not per run. No effect in this run (no background tasks used); kept as a known leak.
4. **Setup cost.** Seeding links 20,756 files (462 MB) in ~10 s; `npm ci` (lock file differs from the base clone) ~25 s; `build:offline` ~20 s. Base clone verified untouched after every run.
