In D:/Projects/realsubagents:
- **Runner:** `node bench/run.ts <task> --mode agent|base|reference [--arm baseline|rsa|rsav1] [--n N] [--keep] [--write-baseline] [--cap-usd 5] [--wall-min 90]`, or `node bench/run.ts --rescore <runDir>`.
- **Locations:** clones in `D:/rsa-bench/repos/` (pi, bilinova); runs in `$RSA_RUNS` or `D:/rsa-bench/runs/<task>/<arm|mode>-<n>/`.
- **Tasks:** `bench/tasks/<id>/task.json` (repo, base, source, label small|large-serial|large-parallel, withhold[], acceptance.command, regression[] {command, parser cargo|vitest-json|node-tap, baselineFailures}; large-parallel tasks are composites with `parts` and `k`) plus `prompt.md`. 13 tasks, all validated.
- **Validation (free):** `bash bench/validate.sh <task>...`: the reference must be accepted, the base rejected; writes the baseline-failure lists.
- **Acceptance:** the named tests pass, and no regression failures outside the baseline list. A check with new failures is re-run once; only repeats count, the others go to `regression.flaky` (D-18). `bench/repos.json` `ignoreFailures` lists live-network tests to ignore.
- **On Windows:** many pi test files contain Windows-only failures, so acceptance names only the commit's new tests (vitest `-t`, node `--test-name-pattern`).
- **Rescore:** `--rescore` re-checks a run from its saved diff.patch, free. Use it after harness fixes, never while a batch is running (CPU contention).
- **Batch:** `[ARM=rsav1] bash bench/batch.sh [rounds]`, resumable. Spend: `node bench/ledger.ts`.
- **Pitfalls:**
  - Prompts must not contradict the hidden tests (check stdout/stderr, platform scope).
  - `git add -A -N` leaves intent-to-add entries that block applying withheld files.
  - Kill leftover processes before acceptance (`killLeftovers` in bench/sh.ts).
  - Git Bash has no pgrep.
