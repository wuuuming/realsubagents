**Dev commands:**
- `npm run typecheck`: tsc 7 with `erasableSyntaxOnly`, so no constructor parameter properties and no enums.
- `npm test`: runs `node --test tests/*.test.ts`. TS runs via Node type stripping; there is no build step.
- `npm run smoke`: runs `bench/smoke.ts`.
  - It starts real Pi 1.5.0 with `--mode rpc --no-session --no-extensions -e extensions/realsubagents/index.ts`.
  - It checks that `get_commands` includes `rsa`.
  - It checks that `prompt "/rsa"` returns disposition `handled` plus a notify `extension_ui_request`.

**Spawning child Pi on Windows:**
- `pi` is a launcher script (`~/.pi/agent/bin/pi-launcher.js`) that spawns a second node.
- Instead, spawn child Pi directly as `node <cli.js>`.
  - Find the CLI with `findPiCli()` in `src/pi-cli.ts`. Lookup order: `RSA_PI_CLI` → `~/.pi/agent/install/current-version` release → local package.
  - Set env `PI_MANAGED_INSTALL_ROOT`.
- RPC framing must split on LF only. Do not use readline.
