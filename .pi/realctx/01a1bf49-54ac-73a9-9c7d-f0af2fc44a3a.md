Runner: `node bench/run.ts <task> --mode agent|base|reference [--n N] [--keep] [--write-baseline] [--cap-usd 5] [--wall-min 90]` (in D:/Projects/realsubagents). Benchmark clones live in `D:/rsa-bench/repos/` (outside the realsubagents repo).

**Tasks & repos**
- `bench/tasks/<id>/task.json`: repo, base commit, source commit, label, withhold[] (test paths checked out from `source` only at acceptance), acceptance.command, optional regression {command, parser cargo|vitest-json|node-tap, baselineFailures}. Plus `prompt.md`.
- `bench/repos.json`: base clone, tree setup links/copies, seed mode, prepare commands.

**Validate a task for free**
- `--mode base` must give accepted=false.
- `--mode reference --write-baseline` applies base..source (minus withheld), must give accepted=true, and writes the regression baseline list (failures the historical fix also has; e.g. pi tui has 5 Windows-only failures in autocomplete/terminal-image).
- Acceptance = named tests pass + no failures outside a baseline list (route D-18). Acceptance must name the task's own test files; whole-suite commands fail on Windows due to pre-existing failures, so they go in `regression`.

**Runs**
- Output: `D:/rsa-bench/runs/<task>/<arm|mode>-<n>/` (result.json, meter.json, trace.jsonl, diff.patch, acceptance.log, regression.log); run dir must not exist yet. Worktree removed unless --keep; junction links removed before deletion.
- Agent mode: pi RPC with `--no-extensions -e realctx -e realtasks -e extensions/rsa-bench-usage`, REALCTX_HOME=<run>/realctx, `--session-dir <run>/sessions`. realtasks is NOT isolated (state lives under PI_CODING_AGENT_DIR). Dialog requests get `cancelled: true`.
- Shell commands run through Git Bash (`C:/Program Files/Git/bin/bash.exe`, override RSA_BASH); timeouts kill the process tree with `taskkill /T /F`.

**BiliNova** (`d65d4bd`, Rust workspace)
- Untracked `native/` (424 MB FFmpeg/libplacebo SDKs) and `native-audio/` must be junctioned from `D:/Projects/BiliNova` or `player-core`'s build.rs panics.
- `cargo test --workspace --no-fail-fast`: 1,202 pass, 4 baseline failures, 15 ignored.
- `crates/bilinova/build.rs` watches `.git/commondir` (exists only in worktrees), so the main clone rebuilds `bilinova` + `bilinova-tests` on every build. Cold test build ~1–2 min; `target/` ~7 GB.

**pi** (`earendil-works/pi` tag v1.5.0)
- `npm ci --ignore-scripts` 64 s, `npm run build` 24 s. `build` fetches model catalogs from the network (can time out); use `npm run build:offline` with the git-ignored `packages/ai/src/providers/data/` present.
- On Windows ~1,040 tests fail at baseline in 8 of 12 packages (root `npm test` also fails in scripts tests: tar "Cannot connect to C:"). `packages/agent` tests all pass (94).
