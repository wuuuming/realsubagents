Benchmark clones live in `D:/rsa-bench/repos/` (outside the realsubagents repo).
- **BiliNova** (`d65d4bd`, Rust workspace): untracked `native/` (424 MB FFmpeg/libplacebo SDKs) and `native-audio/` must be junctioned from `D:/Projects/BiliNova` or `player-core`'s build.rs panics. `cargo test --workspace --no-fail-fast`: 1,202 pass, 4 baseline failures, 15 ignored. Its `crates/bilinova/build.rs` watches `.git/commondir` (exists only in worktrees), so the main clone rebuilds `bilinova` + `bilinova-tests` on every build. Cold test build ~1–2 min; `target/` ~7 GB.
- **pi** (`earendil-works/pi` tag v1.5.0): `npm ci --ignore-scripts` 64 s, `npm run build` 24 s. `build` fetches model catalogs from the network (can time out); use `npm run build:offline` with the git-ignored `packages/ai/src/providers/data/` present. On Windows ~1,040 tests fail at baseline in 8 of 12 packages (root `npm test` also fails in scripts tests: tar "Cannot connect to C:"). `packages/agent` tests all pass (94).
- Acceptance therefore = named tests pass + no failures outside a baseline list (route D-18).
