realsubagents `prompts/v0/` (route R.05.1, PR-4..PR-7):
- `GUIDANCE.md` maps each prompt rule to Anthropic/OpenAI/Google guidance (sources linked). The user asked that prompting reference the vendors' guides.
- `orchestrator.md` (PR-4 brief + PR-5 dispatch) and `worker.md` (PR-6 contract + PR-7 Report) are family-neutral and go in via Pi `--append-system-prompt <path>` from the first request. Never change the system prompt mid-session (cache).
- `overlays/<provider>-<role>.md` is appended for that provider's models (e.g. openai: passivity + test over-production).
- Dynamic content (dispatch, brief, Reports, steers) goes in user messages with XML tags (`<task> <acceptance> <paths> <other_groups> <brief> <report>`). Every relay message ends with `elapsed Ns` (Anthropic multiagent time signal). Unattended workers are continued at most 2 times after a text-only end of turn.
- Fairness rule: no cost-saving instruction in the rsa arm that the baseline arm lacks (otherwise v0.05 measures a prompt, not the architecture); such knobs are tuned in both arms. Effort stays at `high`, like the baseline.
