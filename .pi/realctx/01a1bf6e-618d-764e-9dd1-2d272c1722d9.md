**Settings schema v3** (realctx upstream commit `90b356c`, 2026-11-09)

On load, a config with version < 3 has its whole `context` and `history` sections reset to the new defaults. This includes custom values and `history.model`.
- A `.bak` is written next to config.json.
- A warning is shown (console.warn in RPC/no-UI mode).
- Connections, keys, `rewriteModel` and memories are kept.

The user's config had `history.model = openai/gpt-6-luna`, which seemed unavailable (the historian kept failing in interactive sessions). If that config is < v3, it gets reset on load. The user does not want haiku as historian, in their own config or in benchmarks.

**Model fallbacks**
- `rewriteModel` empty: memory edit/merge calls use the session model (opus in benchmarks).
- `history.model` empty: uses rewriteModel, else the session model.

**v3 defaults**
- Context/history `protectTurns`: 24.
- `context.applyThreshold`: 0.4, `applyMaxTokens` 0 (no ceiling).
- `emergencyThreshold`: 0.8.
- `captureMinTokens` and `dropMinTokens`: 0.
- `history.prepareThreshold`: 0.3, `prepareMaxTokens` 0.
- History chunks: 8k–50k tokens.

**Cache TTL**
- `context.cacheTtl` was removed.
- It was replaced by `cacheTtlAuto` (default true: daily background fetch of models.dev; Anthropic/OpenAI estimate 5m) plus `cacheTtlByModel` overrides.
- Pi's `PI_CACHE_RETENTION=long` gives 1h Anthropic caching, which realctx does not detect. Set the override to match.

**realsubagents benchmark (route D-24, commit `2c8bb95`, supersedes D-20/D-23 haiku)**
- `bench/pins.json` pins realctx to `90b356c`.
- `bench/run.ts` refuses agent runs on another commit unless `RSA_ALLOW_DRIFT=1`.
- `bench/run.ts` defaults `REALCTX_MODEL` to "" (env `RSA_REALCTX_MODEL` overrides).
- `realctxRunConfig()` writes a per-run config with `version: 3`. It:
  - drops the user's context/history sections;
  - sets `rewriteModel: ""` and `history.model: ""`, so memory edits and history summaries use the session model (Opus);
  - sets `cacheTtlAuto: false`;
  - sets `cacheTtlByModel {<session model>: 5m|1h}`.
- Verified against v3's `loadSettings`: no migration, no backup.
- The pilot run with the old haiku setup was renamed `D:/rsa-bench/runs/pi-tui-wrap-boundary/pilot-haiku-1`. It is not baseline data, but `bench/ledger.ts` still counts its $1.42.

**Memory location**
- realctx writes project-shared memories into `<cwd>/.pi/realctx/`, i.e. into the benchmark tree.
- The runner excludes `.pi/realctx` and `.rsa-seed-manifest.json` from diff.patch.
